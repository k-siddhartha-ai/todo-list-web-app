
# 🚀 To-Do List Web Application

A modern, responsive To-Do List web application built using HTML5, CSS3, and JavaScript. It helps users organize daily tasks through a clean interface, real-time search, task management controls, and persistent browser storage.

## 🌐 Live Demo

**[👉 Try the Live To-Do List Application](https://todolist-tau-roan.vercel.app/)**

## ✨ Key Features

- ➕ **Add Tasks:** Quickly add new tasks to your list.
- ✏️ **Edit Tasks:** Update existing tasks whenever needed.
- ✅ **Complete Tasks:** Mark tasks as completed or pending.
- 🗑️ **Delete Tasks:** Remove tasks you no longer need.
- 🔍 **Live Search:** Find tasks instantly by typing their names.
- ~~**Strikethrough Effect:**~~ Completed tasks are visually distinguished with a green line through the text.
- 💾 **Persistent Storage:** Save tasks in browser Local Storage.
- 🔄 **Data Persistence:** Keep tasks after refreshing the page.
- 📱 **Responsive Design:** Enjoy a clean interface on desktop and mobile screens.
- 🎨 **Modern UI:** Gradient background, rounded task cards, subtle shadows, and interactive buttons.

## 🛠️ Technologies Used

- HTML5 — Page structure
- CSS3 — Responsive styling, Flexbox, transitions, and visual effects
- JavaScript (ES6+) — Application logic and event handling
- DOM Manipulation — Dynamic task rendering
- Arrays and Objects — Task data management
- JSON — Data serialization and deserialization
- Browser Local Storage — Persistent task storage
- Google Fonts — Poppins typography
- Vercel — Deployment and hosting

## ⚙️ Getting Started

### Prerequisites

- A modern web browser
- An internet connection to load the Google Fonts stylesheet

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/k-siddhartha-ai/todo-list-web-app.git
   ```

2. Open the project folder:

   ```bash
   cd todo-list-web-app
   ```

3. Open `ToDoList/index.html` in your browser.

No additional package installation or backend server is required.
