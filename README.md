
# To-Do List Web Application

A responsive and interactive To-Do List application built using HTML, CSS, and JavaScript. This project helps users organize daily tasks with a clean interface and persistent browser storage.

## Live Demo

**[Open the To-Do List Application](https://todolist-tau-roan.vercel.app/)**

## Features

- Add new tasks
- Edit existing tasks
- Mark tasks as completed or pending
- Delete tasks
- Search tasks by name
- Display a strikethrough effect for completed tasks
- Save tasks using browser Local Storage
- Retain tasks after refreshing the page
- Responsive interface with modern CSS styling

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Arrays and Objects
- JSON
- Browser Local Storage
- Vercel

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/k-siddhartha-ai/todo-list-web-app.git
   ```

2. Open the `ToDoList` folder.
3. Open `index.html` in your browser.
